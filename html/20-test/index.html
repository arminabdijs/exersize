مقدمه HTML

HTML زبان نشانه‌گذاری است که برای ساخت صفحات وب استفاده می‌شود.

عنصر کاربرد نوع
header سر صفحه سمانتیک
main محتوای اصلی سمانتیک
footer پای صفحه سمانتیک

مقدمه HTML

HTML زبان نشانه‌گذاری است که برای ساخت صفحات وب استفاده می‌شود.

  • header برای سر صفحه
  • nav برای منوی ناوبری
  • main برای محتوای اصلی
  • section برای بخش‌بندی محتوا
  • article برای مقالات
  • aside برای محتوای جانبی
  • footer برای پای صفحه

مقدمه HTML

استفاده از عناصر سمانتیک HTML باعث بهبود دسترسی، SEO و خوانایی کد می‌شود. این عناصر به موتورهای جستجو و فناوری‌های کمکی کمک می‌کنند تا محتوا را بهتر درک کنند. 

<article>
    <h2>عنوان مقاله</h2>
    <p>محتوای مقاله...</p>
    <time datetime="2024-01-01">تاریخ انتشار</time>
</article>

راهنمای تگ‌های HTML

در این بخش می‌توانید اطلاعات تکمیلی درباره تگ‌های مختلف HTML را مطالعه کنید:

  • <time> برای نمایش تاریخ و زمان
  • <figure> برای تصاویر با توضیح
  • <details> برای محتوای قابل باز و بسته شدن
